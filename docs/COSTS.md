# 運用費用と無料枠（2026-11-14 時点）

| 項目 | 使用サービス | 費用 | 無料枠・制限 |
|---|---|---|---|
| ホスティング | GitHub Pages（公開リポジトリ） | 0円 | サイト1GB・帯域 月100GB目安（ソフト制限） |
| ビルド・公開 | GitHub Actions（公開リポジトリ） | 0円 | 公開リポジトリは無料 |
| 音声認識 | Whisper（利用者の端末で実行） | 0円 | 端末の性能に依存 |
| 翻訳 | LFM2-ENJP-MT / FuguMT（利用者の端末で実行） | 0円 | 同上 |
| モデル配布 | Hugging Face Hub から利用者が直接取得 | 0円 | 初回のみ約150〜500MB（PC既定は実測500MB）を各利用者がダウンロード |
| 読み上げ | OS標準の音声合成 | 0円 | 声の種類はOSに依存 |
| ライブ音声 | 未契約 | 0円 | Broadcastify Calls は契約時に従量課金（最低5ドル〜） |

**現在の月額：0円**

## 将来の注意点
- 利用者が増えると GitHub Pages の帯域（月100GB目安）に近づく可能性。ページ本体は約28MB（大半はAI実行環境のwasm）で、2回目以降はキャッシュされる。超える場合は Cloudflare Pages（無料・帯域無制限）へ移行可能。
- AIモデルは Hugging Face から配信されるため当方の帯域は消費しない。商用化時は同社の利用規約とモデルの再配布条件を確認し、必要なら自前配信へ切り替える。
- LFM2 は会社の年商が1,000万ドル以上になると有料ライセンスが必要。
