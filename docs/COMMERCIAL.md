# 商用販売に向けた改善提案（2026-11-14）

> 開発上の提案です。法務・税務の判断は専門家の確認を前提とします。

## 1. 現状の強み
- **運用費0円の構造**：AIを利用者の端末で動かすため、利用者が増えてもサーバー費用が増えない。
- **音声を外に出さない**：プライバシー面・規約面で説明しやすい。
- **無線特有の処理**：10コード・呼出符号・定型句・聞き違い補正・不確かな語の明示。汎用翻訳アプリとの差別化点。

## 2. 想定する利用者
| 層 | 使い方 |
|---|---|
| 海外の緊急無線を聞く愛好家（スキャナー趣味） | 自分の受信機・好きな配信を日本語で理解する |
| 報道・リサーチ | 米国の大規模事案の現場無線の把握（公開・転載は不可の範囲で） |
| 在米・渡航予定の日本人 | 地域の緊急情報の雰囲気を知る |
| 英語学習者 | 実際の業務無線のリスニング教材として |

## 3. 料金体系の案
| 版 | 内容 | 運営費 |
|---|---|---|
| 無料版 | デモ局、利用者が自分で追加する局（受信機・タブ音声・配信URL）、履歴、読み上げ | 0円（現状のまま） |
| 有料版（月額） | 許諾済みライブ配信（例：Broadcastify Calls 経由）の受信、複数局の同時監視、キーワード通知、履歴の書き出し強化 | 提供元への従量課金が発生 → 月額料金で回収 |

- ライブ配信は提供元への支払いが**利用量に比例**するため、買い切りではなく月額（または利用量の上限付き）が適切。
- 有料版を始めるには、決済の仕組み（例：Stripe）と、利用者ごとの利用量管理（ログイン）が必要になり、**初めてサーバー側の仕組みが必要**になる。無料枠のあるサービス（例：Supabase、Cloudflare Workers）で小さく始められるが、費用と規約を事前に確認する。

## 4. 販売前に必要なこと（優先順）
1. **ライブ音声の提供元の確定**（docs/LEGAL.md、docs/outreach/ に問い合わせ文案）
2. **弁護士確認**：電波法第59条との関係、配信元規約、利用規約・プライバシーポリシーの確定（アプリ内に案を掲載済み）
3. **特定商取引法に基づく表記**（有料販売する場合に必要）
4. **運営者情報の確定**（規約内の〔運営者名〕〔連絡先〕〔管轄裁判所〕）
5. **LFM2 の商用条件の再確認**（年商1,000万ドル以上で有料ライセンス）。FuguMT は CC BY-SA の表示義務
6. **スマートフォン実機での検証**（iPhone / Android、メモリ・発熱・速度）
7. 配信先を Cloudflare Pages（無料・ヘッダー設定可）へ移行し、CSP をヘッダーで強化

## 5. 製品としての改善提案
| 優先 | 改善 | 効果 |
|---|---|---|
| 高 | 許諾済み局の地図表示と一覧（提供元確定後） | 「世界の通信を見渡す」体験の完成 |
| 高 | 初回ダウンロードの短縮（スマホは軽量モデルを既定、段階的な読み込み） | 離脱を減らす |
| 済 | キーワード通知（v1.2で実装。端末内で動くため運営費0円） | 有料版では多局同時監視と組み合わせて価値を高める |
| 中 | 複数局の同時受信・切り替え | 管制センターらしさ |
| 済 | AudioWorklet への移行（v1.2） | 音声処理の安定化 |
| 低 | 英語以外（スペイン語など）の無線 | 対応国の拡大 |
| 低 | 用語辞書の拡充（地域ごとの10コード差の吸収） | 翻訳の正確さ |
