# RADIO LINGUA 操作マニュアル

公開URL：https://co-30.github.io/radio-lingua/

海外の警察・消防・救急の無線（英語）を、日本語の字幕と読み上げに変えるアプリです。
アプリのインストールやアカウント登録は不要で、ブラウザで開くだけで使えます。

## 1. はじめて使うとき
1. 上のURLを開きます。
2. 「デモ交信」が選ばれた状態で **「翻訳を開始」** を押します。
3. 「AIモデルをダウンロードします」と表示されたら **「ダウンロードして開始」** を押します。
   - 初回だけ、AIのデータ（PCで約500MB、スマホで約150〜370MB）をダウンロードします。Wi-Fiでの利用をおすすめします。
   - 2回目以降はダウンロード済みのデータを使うので、すぐに始まります。
4. デモの交信（架空の通報、約44秒）が流れ、黒い画面に日本語の字幕が順に表示されます。

## 2. 画面の見方
| 場所 | 内容 |
|---|---|
| 黒い字幕画面 | 最新の交信の日本語訳。下の小さな文字は英語の原文 |
| 色付きの名札 | 呼出符号（部隊名）。赤＝消防、黄＝救急、青＝警察 |
| 枠付きの小さな札 | 無線コードの意味（例：10-4＝了解）。機関によって意味が違う場合があります |
| 下線付きの文字 | 交信の種類（警察・消防・救急・その他）の推定 |
| 交信ログ | これまでの字幕。新しい順に並びます |
| 右上の丸い点 | AIの状態。緑＝準備完了、黄＝準備中、赤＝失敗 |

## 3. 音声の取り込み元
| 選択肢 | 使い方 |
|---|---|
| デモ交信 | 動作確認用の架空の交信（合成音声） |
| 音声ファイル | 録音済みの英語の無線音声（mp3・wav・m4a など）を選ぶと、再生しながら翻訳します |
| マイク・受信機 | 受信機（スキャナー）のスピーカーの近くに端末を置きます。初回はマイクの許可を求められます |
| タブ音声 | パソコンの Chrome・Edge のみ。無線を再生しているタブを選び、「タブの音声も共有する」をオンにします |

止めるときは **「停止」** を押します。

## 4. 読み上げ
「日本語で読み上げ」にチェックを入れると、字幕を音声でも読み上げます。
マイクで取り込んでいるときは、読み上げの声を拾わないようイヤホンを使ってください。

## 5. 設定（右上のボタン）
| 項目 | 説明 |
|---|---|
| 音声認識 | 高精度（PC向け）／標準／軽量（スマホ向け）。端末に合わせて自動で選ばれます |
| 翻訳 | 高品質（LFM2）／省メモリ（FuguMT） |
| 英語の原文も表示 | オフにすると日本語だけを表示 |
| 読み上げの速さ・字幕の大きさ | お好みで調整 |
| GPUを使わない | 字幕が出ない・動作が不安定なときに試してください |

設定を変えたあとは、次に「翻訳を開始」を押したときにAIを読み込み直します。

## 6. 交信ログ
- 字幕は **この端末の中だけ** に保存されます（最大1,000件）。外部には送られません。
- 「テキストで保存」「JSONで保存」で書き出せます。
- 「履歴を消去」で全件削除します（元に戻せません）。

## 7. うまく動かないとき
| 症状 | 対処 |
|---|---|
| 「AIモデルを読み込めませんでした」 | 通信状況を確認し、もう一度「翻訳を開始」。容量不足の場合は設定で「軽量」「省メモリ」に |
| 字幕が出ない | 音が小さすぎないか確認。設定の「GPUを使わない」を試す |
| 字幕が遅れる・「追いついていません」と出る | 設定で音声認識を「標準」または「軽量」に |
| タブ音声が選べない | パソコンの Chrome・Edge でのみ使えます |
| 読み上げされない | iPhoneはマナーモードを解除。端末に日本語の音声があるか確認 |

## 8. 注意事項
- AIによる翻訳には誤りが含まれます。緊急時の判断には使わないでください。
- 無線の内容や翻訳結果を公開・転載しないでください（法令で禁じられている場合があります）。
- 配信サイトを利用する場合は、そのサイトの利用規約を守ってください。

## 9. 動作環境
- PC：Chrome / Edge（推奨、GPUで高速）、Safari、Firefox の最新版
- スマートフォン：iPhone（Safari）、Android（Chrome）の最新版。メモリ4GB以上を推奨
