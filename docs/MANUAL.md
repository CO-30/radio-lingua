# RADIO LINGUA 操作マニュアル（v1）

公開URL：https://co-30.github.io/radio-lingua/

海外の警察・消防・救急の無線（英語）を、日本語の字幕と読み上げで理解するためのアプリです。
インストールやアカウント登録は不要で、ブラウザで開くだけで使えます。

## 1. はじめて使うとき（約2分）
1. URLを開くと、世界地図が表示されます。
2. 地図上の「デモ局」のマーカー（米国の中央付近）を押し、右側（スマホでは下）に出たパネルの **「聞く」** を押します。
3. ライブ翻訳画面で **「受信して翻訳」** を押します。
4. 「AIモデルをダウンロードします」と出たら **「ダウンロードして開始」** を押します。
   - 初回だけAIのデータ（PCで約500MB、スマホで約150〜370MB）をダウンロードします。Wi-Fiをおすすめします。
   - 2回目以降は端末に保存されたデータを使うので、すぐに始まります。
5. 架空の通報（約44秒）が流れ、交信ごとに原文と日本語訳が並びます。

## 2. 画面の構成
PCは左の縦メニュー、スマートフォンは画面下のメニューで切り替えます。

| メニュー | できること |
|---|---|
| 地図 | 世界の受信状況を見る。国を押すとその国の局と、準備中の提供元を表示 |
| 無線局 | 局の一覧・検索・絞り込み、局の追加、準備中の提供元の確認 |
| ライブ翻訳 | 受信中の交信を原文と日本語訳で表示。受信中はメニューに緑の点 |
| お気に入り | ☆を付けた局と、重要な交信 |
| 履歴 | これまでの交信の検索・絞り込み・書き出し・消去 |

右上には現在時刻（UTC・日本時間）とAIの状態（緑＝準備完了、黄＝準備中、赤＝失敗）を表示します。

## 3. 地図の見方
| 表示 | 意味 |
|---|---|
| 青い点の国 | 受信できる局がある国 |
| アンバー（黄）の点の国 | 提供元の利用許諾・契約を確認中（まだ受信できません） |
| 丸いマーカー | 局。押すと名前とパネルを表示。受信中は緑に光ります |
| 右下の ＋／−／地球 | 拡大・縮小・最初の表示に戻す。ドラッグで移動、2本指で拡大縮小もできます |

## 4. ライブ翻訳画面
- **受信して翻訳**：局の音声を取り込み、交信ごとに翻訳します。止めるときは「停止」。
- **録音ファイルを翻訳**：手元の録音（mp3・wav・m4a など）を再生しながら翻訳します。
- **新しい交信を読み上げ**：オンにすると、届いた訳を自動で日本語音声で読み上げます。
- 波形とレベルの帯は、いま受信している音の大きさです。

交信1件ごとの表示：
| 表示 | 意味 |
|---|---|
| 左の色の線とアイコン | 警察（盾）・消防（炎）・救急（十字）の推定 |
| 色付きの名札 | 呼出符号（例：消防車12、救急車7） |
| 枠付きの札 | 無線コードの意味（例：10-4＝了解）。機関によって異なる場合があります |
| 黄色の下線の語 | AIの聞き取りが不確かな語（確信度50%未満）。訳にも誤りがある可能性があります |
| 緑の小さな札 | 専門用語。押すと説明が出ます（例：交差道路、マイル標識） |
| スピーカーのボタン | その交信を読み上げ／停止 |
| ☆ボタン | 重要な交信として残す（お気に入りに表示） |

## 5. 局を追加する（お手持ちの受信機・配信）
「無線局」→ **「局を追加」**（地図で国を選んで「〇〇に局を追加」でも可）。
1. 局の名前、種別（警察・消防・救急、複数可）、国・地域を入力します。
2. 音声の取り込み方法を選びます。
   - **マイク・受信機**：受信機（スキャナー）のスピーカーの近くに端末を置きます。
   - **ブラウザのタブ音声**（PCの Chrome・Edge）：配信を再生しているタブを選び、「タブの音声も共有する」をオンにします。
   - **配信URL**：ご自身の受信機の配信など（https）。配信側が外部からの取り込みを許可していないと翻訳できません（画面でお知らせします）。
3. 「この音声を受信・翻訳する権利があることを確認しました」にチェックして「追加して開く」。

追加した局はこの端末だけに保存され、地図の国の中心付近に表示されます。削除は「無線局」の各局の「削除」から。

## 6. 設定（右上のボタン）
| 項目 | 説明 |
|---|---|
| 音声認識 | 標準（おすすめ）／高精度（高性能PC・録音向け）／軽量（スマホ向け） |
| 翻訳 | 高品質（LFM2）／省メモリ（FuguMT） |
| 英語の原文も表示 | オフにすると日本語だけ |
| 新しい交信を自動で読み上げ／速さ／文字の大きさ | お好みで |
| 交信の履歴をこの端末に保存 | オフにすると画面を閉じた時点で消えます |
| GPUを使わない | 字幕が出ない・不安定なときに |

## 7. うまく動かないとき
| 症状 | 対処 |
|---|---|
| 「AIモデルを読み込めませんでした」 | 通信状況を確認してもう一度。容量不足なら設定で「軽量」「省メモリ」に |
| 字幕が出ない | 音が小さすぎないか、波形が動いているか確認。設定の「GPUを使わない」を試す |
| 「処理が追いついていません」と出る | 設定で音声認識を「標準」または「軽量」に |
| 配信URLで翻訳できない | 配信側が取り込みを許可していません。タブ音声かマイクをお使いください |
| 読み上げされない | iPhoneはマナーモードを解除。端末に日本語の音声があるか確認 |

## 8. 注意事項
- AIによる翻訳には誤りが含まれます。緊急時の判断や公式情報の代わりには使わないでください。
- 無線の内容や翻訳結果を公開・転載しないでください（法令で禁じられている場合があります）。
- 配信サイトを利用する場合は、そのサイトの利用規約を守ってください。
- 音声・字幕・履歴はこの端末の中だけで処理・保存され、外部には送られません。

## 9. 動作環境
- PC：Chrome／Edge（推奨、GPUで高速）、Safari、Firefox の最新版
- スマートフォン：iPhone（Safari）、Android（Chrome）の最新版。メモリ4GB以上を推奨
