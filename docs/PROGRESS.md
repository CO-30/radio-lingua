## v1 の実機確認（公開サイト・PCのブラウザ・実モデル）
- 地図→デモ局→ライブ翻訳で、交信が原文と訳の並びで表示されることを確認
- 確信度による「不確かな語」の表示は実モデルで正しく動作（例：Medics 29%、Medic 25%、Street 42% を検出）
- 確認時のPCは負荷が高く、GPUの初回推論に2〜4分かかる状態だった。
  → 準備段階のウォームアップと、30秒/60秒で応答しない場合のCPU自動切替を追加し、停止しないことを確認
- この状態では1交信の認識に8〜14秒（平常時は約4秒）。「追いついていません」の案内が設定に応じて出る

## 実測値
### 精度（GitHub Actions 上の実モデル、デモ交信6件、docs/benchmarks/latest.md）
| 音声認識 | 単語誤り率 |
|---|---|
| Whisper base（標準・既定） | 4.0% |
| Whisper small（高精度） | 2.7% |
（旧デモ＝機械的な合成音声では base 32% / small 16%。声の自然さで大きく変わる）

### 速度（公開サイト、PCのブラウザ、8.6秒の交信1件）
| 構成 | 認識にかかった時間 |
|---|---|
| base・GPU | 3.9秒 |
| base・CPU | 4.1秒 |
| small・GPU | 9.3秒（交信より長く、ライブでは遅れる） |
| small・CPU | 13.9秒 |
翻訳は1交信あたり 0〜5秒（定型句は辞書で即時）。初回のAI準備は約500MB・84秒（高速回線）。

## 記録
### 2026-11-14
- 調査：Broadcastify はライブフィードの再配信を禁止、Calls API は審査制・有料で翻訳アプリを許容。OpenMHz は規約未公開。
- 方式決定：端末内AI（費用0円・音声を外に出さない）
- デモ音声：架空の6交信を meSpeak で合成し、ffmpeg で無線風に加工（highpass 320Hz, lowpass 3100Hz, コンプレッサー, スケルチ音, ピンクノイズ）
- 修正：開始前に「受信中」が表示される不具合（CSS の display 指定が hidden 属性を上書き）→ `[hidden]{display:none!important}` で修正し、テストを追加

- v0.2：実モデル検証。翻訳を文ごと・定型句辞書・呼出符号分離に変更、誤訳補正、繰り返し除去、数字+複数名詞の崩れ対策
- デモ音声を Kokoro-82M（自然な声）で再生成 → 誤り率 32%→4%
- 交信区切りを900msに（自然な文間の息継ぎ≒0.5秒で誤分割していた）
- 速度実測により既定を Whisper base に。高精度は fp16 で容量半減
- 精度測定の結果が履歴に混ざる不具合を修正
- CSP・no-referrer・モデル版固定、セキュリティ監査

- v1：世界の通信管制センターとして全面刷新（React+TS、点描の世界地図、5画面、確信度表示、用語補足、局の追加、お気に入り）
- 実機で停止に見える症状を調査：原因はGPUの初回推論の遅さ（コードの不具合ではない）。ウォームアップとCPU自動切替で対策
- Whisper の聞き違い補正を追加（"and root"→en route、"Medics 7"→救急車7）
- v1.1：AI実行環境の二重同梱を解消（公開ファイル 55MB→28MB）、PWA化（ホーム画面に追加・圏外でも画面が開く）、
  アプリ内に規約類（案）、技術構成資料・商用化提案・問い合わせ文案を作成
- v1.1 実機確認（公開サイト・実モデル）：新しいAI実行環境の読み込み先で正常動作、Service Worker 有効、デモ6交信すべて正しく翻訳。
  聞き違い補正（and root→了解、現場へ向かう／Medics 7→救急車7）が実際の認識結果で効いていることを確認
- v1.2：キーワード通知（登録語・提案語・強調表示・通知音・画面を見ていないときの端末通知・履歴の「通知のみ」）、
  音声取り込みを AudioWorklet に移行（非対応環境は従来方式に自動切替。両方式でデモ6交信を確認）。単体60件・画面通しテスト成功
- v1.2 実機確認：AudioWorklet で取り込み、キーワード通知が実モデル出力で一致（英語 structure fire／日本語 胸の痛み）。
  「不確か」の誤検知が多い問題を発見（Southbound・Mile・40. など正しく聞き取れている語）。原因は大文字小文字・句読点だけが違う候補に
  確率が分かれること → 表記ゆれの確率を合算し、記号だけの語は判定しないよう修正（単体テスト3件追加）

  残ったのは本当の聞き違い（root）や迷いのある語（Medic/Medics, sedan, 2）。さらに数詞と数字（two/2）を同じ語として扱うよう追加
