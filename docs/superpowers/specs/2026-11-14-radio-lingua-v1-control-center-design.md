# RADIO LINGUA v1 設計書：世界の通信管制センター（2026-11-14）

前提：v0.2（端末内AI・交信区切り・無線用語・翻訳）は実モデルで検証済み。v1 は画面全体を
「世界の通信をリアルタイムで見渡せる、近未来的なプレミアム管制センター」に作り直す。

## 目的と利用者
- 海外の警察・消防・救急の無線を、日本語で「いま何が起きているか」理解したい日本語話者。
- 技術知識なしで、地図から局を選び → ライブ翻訳を見る、が直感的にできること。

## ゴール / 非ゴール / 失敗条件
- ゴール：世界地図中心の5画面（地図・無線局・ライブ・お気に入り・履歴）、PC/スマホ最適化、
  ライブ画面で原文と訳の並列・波形・不確かな語の明示・用語補足・交信ごとの読み上げ・重要マーク。
- 非ゴール：アカウント・課金・サーバー。許諾のない音声の取得。
- 失敗条件：仮データや未許諾の局を「受信できる」ように見せること。

## 方式（比較と判断）
| 論点 | 案 | 判断 |
|---|---|---|
| 画面技術 | 素のJS継続 / React+TS / Preact | **React+TS**：画面と状態が増えるため保守性を優先（指示書の候補）。検証済みの音声・翻訳モジュールはJSのまま再利用 |
| 世界地図 | タイル地図（MapLibre＋配信元） / 点描の自前地図 | **点描の自前地図**：Natural Earth（パブリックドメイン）からビルド時に生成。API キー・配信費ゼロ、管制センターらしい独自の見た目、オフライン可 |
| 国名 | 自前の訳語表 / ブラウザの Intl.DisplayNames | **Intl.DisplayNames('ja')**：追加データ不要で全200か国超に対応 |
| 不確かな語 | 推測（辞書にない語） / Whisper の確信度 | **確信度**：デコード各段の確率を記録し、低い語を明示（推測しない） |
| ルーティング | ライブラリ / ハッシュ式の自前 | **ハッシュ式**：GitHub Pages で404にならず、依存も増やさない |

## 局の扱い（法令順守）
- 受信可能として表示するのは「デモ局（架空の交信）」と「利用者が自分で追加した局（マイク・タブ音声・利用者の配信URL）」だけ。
- 提供元（Broadcastify Calls / OpenMHz）は対応国をアンバー（未確認）で示し、「契約待ち」「許諾確認中」と明記。局は載せない。
- 許諾が取れた提供元・局は `src/data/` に追加するだけで地図・一覧に出る構造にする。

## デザイン
- 色：背景 #101B2B、通信・選択 #20B9E8、翻訳・正常 #27C99A、注意・未確認 #F5A623。意味のある所にだけ使う。
- 警察・消防・救急は「アイコン＋色」で区別（色だけに頼らない）。
- 主役は点描の世界地図と、受信中の局から立ち上がる信号の波紋。他は静かに。
- 文字：日本語は端末標準（BIZ UDPゴシック等）、英数字の見出し・計器表示は Chakra Petch（OFL、自前配信）。
- PC：左の縦メニュー＋本文（地図画面は右に情報パネル）。スマホ：下部メニュー5項目、地図は下からのシート。
