## 実測値
### 精度（GitHub Actions 上の実モデル、デモ交信6件、docs/benchmarks/latest.md）
| 音声認識 | 単語誤り率 |
|---|---|
| Whisper base（標準・既定） | 4.0% |
| Whisper small（高精度） | 2.7% |
（旧デモ＝機械的な合成音声では base 32% / small 16%。声の自然さで大きく変わる）

### 速度（公開サイト、PCのブラウザ、8.6秒の交信1件）
| 構成 | 認識にかかった時間 |
|---|---|
| base・GPU | 3.9秒 |
| base・CPU | 4.1秒 |
| small・GPU | 9.3秒（交信より長く、ライブでは遅れる） |
| small・CPU | 13.9秒 |
翻訳は1交信あたり 0〜5秒（定型句は辞書で即時）。初回のAI準備は約500MB・84秒（高速回線）。

## 記録
### 2026-11-14
- 調査：Broadcastify はライブフィードの再配信を禁止、Calls API は審査制・有料で翻訳アプリを許容。OpenMHz は規約未公開。
- 方式決定：端末内AI（費用0円・音声を外に出さない）
- デモ音声：架空の6交信を meSpeak で合成し、ffmpeg で無線風に加工（highpass 320Hz, lowpass 3100Hz, コンプレッサー, スケルチ音, ピンクノイズ）
- 修正：開始前に「受信中」が表示される不具合（CSS の display 指定が hidden 属性を上書き）→ `[hidden]{display:none!important}` で修正し、テストを追加

- v0.2：実モデル検証。翻訳を文ごと・定型句辞書・呼出符号分離に変更、誤訳補正、繰り返し除去、数字+複数名詞の崩れ対策
- デモ音声を Kokoro-82M（自然な声）で再生成 → 誤り率 32%→4%
- 交信区切りを900msに（自然な文間の息継ぎ≒0.5秒で誤分割していた）
- 速度実測により既定を Whisper base に。高精度は fp16 で容量半減
- 精度測定の結果が履歴に混ざる不具合を修正
- CSP・no-referrer・モデル版固定、セキュリティ監査
