# Phase 1 無料技術の調査と実現可能性（2026-11-14）

## 結論
**サーバー不要・0円で実現可能。** 音声認識と翻訳を利用者のブラウザ内で動かす構成にする。
ボトルネックは技術ではなく「ライブ音声の利用許諾」（docs/LEGAL.md）。

## 音声認識
- Whisper を Transformers.js（ONNX Runtime Web）でブラウザ内実行できる。WebGPU があれば高速、無ければWASM（CPU）で動く。
- 英語専用の base.en / tiny.en を採用（多言語版より英語精度が高く軽い）。将来の多言語対応では多言語版に切り替える。

## 読み上げ
- Web Speech API（OS標準）。無料・通信不要。iOSは利用者操作中に一度鳴らす必要がある（実装済み）。

## 音声の取り込み
- ファイル・デモ：音声要素を再生しつつ同じ経路で解析（再生と字幕が同期）
- マイク：受信機（スキャナー）の音を拾う
- タブ音声：PCのChrome/Edgeで、利用者が開いた配信サイトの音声を取り込む（getDisplayMedia）
- 交信の区切り：無線は「送信→無音」を繰り返すため、無音検出で1交信=1字幕に分けられる（デモ音声で6/6を確認）

## 作業環境の制約（開発時）
- この開発環境からは Hugging Face に接続できないため、実モデルのテストは公開後に実ブラウザで行う。
- 画面・音声処理の通しテストは、AIをモックにして Chrome（PC/スマホ幅）で自動化済み。
